# WRS_ATP

WS 性能验收文档仓库。当前收录扫描曝光光刻机六自由度晶圆台（Wafer Stage，WS）自身性能验收指标与术语资料。

## 文档

- [WS自身性能验收指标与术语定义](docs/WS自身性能验收指标与术语定义.md)：验收边界、指标定义、测试条件与参考资料。
- [贡献与维护规范](CONTRIBUTING.md)
- [变更记录](CHANGELOG.md)

## 使用

使用 GitHub 或支持 Markdown 的编辑器阅读。当前仓库仅包含文档，无需安装依赖，也没有应用启动或自动化测试步骤。

文档中的示例工况与指标定义不能直接替代双方确认的验收协议；具体限值、测试条件及判据应在项目协议中明确。

## 仓库组织

- `docs/`：技术文档。
- `main`：主分支。
- 后续修改使用主题分支并提交 Pull Request，说明修改依据与影响。

当前未声明开源许可证；使用与分发权限需向仓库所有者确认。
