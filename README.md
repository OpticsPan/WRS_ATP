# WRS_ATP

先进扫描曝光光刻机六自由度晶圆台（Wafer Stage，WS）的技术调研与验收资料仓库。

## 当前阶段

**技术调研阶段。** `main` 保存已归档的调研成果；文档合并不代表数值限值、验收协议或设备性能已经批准。当前包含原始指标框架，以及基于16项来源整理的36项补充候选条款。

建议依次阅读指标框架、调研补充和后续任务清单。先确定整机套刻的统计口径与WS误差预算，再冻结各项验收限值。

## 使用

使用 GitHub 或支持 Markdown 的编辑器阅读。当前仓库仅包含文档，无需安装依赖，也没有应用启动或自动化测试步骤。

文档中的示例工况与指标定义不能直接替代双方确认的验收协议；具体限值、测试条件及判据应在项目协议中明确。

## 仓库组织

- `docs/`：技术文档。
- `.github/`：Pull Request模板。
- `main`：主分支。
- 后续修改使用主题分支并提交 Pull Request，说明修改依据与影响。
- 已合并且不再用于工作的主题分支在核对 `main` 后删除；历史由提交和PR保留。
- 本地下载、脚本日志和临时结果放入 `work/`；本地导出放入 `outputs/`。二者默认忽略，长期维护的资料应有选择地纳入 `docs/`。

当前未声明开源许可证；使用与分发权限需向仓库所有者确认。
